# KNN Project

## Overview
This project uses the **K-Nearest Neighbors (KNN)** algorithm to perform classification using Python.

---

## Tools
- Python  
- Pandas  
- Scikit-learn  
- Matplotlib  

---

## Steps
1. Load the data  
2. Preprocess and scale features  
3. Train KNN model  
4. Test and evaluate results  

---

## Result
The model predicts the class based on nearest data points.  
Choosing the right **K value** improves accuracy.
